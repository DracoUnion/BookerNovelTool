# BookerNovelTool 代码结构

ApacheCN 小说文本分析与生成工具：把 EPUB 小说拆章、按模块并行聚合为分析报告，也支持从简介生成中文网文并计算风格/质量指标。命令行入口：`BookerNovelTool`（`python -m BookerNovelTool`），见 pyproject.toml。

代码全部位于 `BookerNovelTool/` 包内，按职责分为 4 类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一入口。构建顶层 `argparse` 解析器（含 LLM 公共参数：`-m/--model`、`-k/--key`、`-H/--host`、`-tm/--temp`、`-retry`、`--emb` 等），遍历各模块调用其 `reg_subparser(subparsers)` 注册子命令，最后 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.10.29.0，SATA 协议，作者 wizardforcel）。
+ `metrics/` — `metrics` 子命令的子包：`tool.py`（`MetricsOrchestrator` 编排器 + CLI 入口 `metrics`）、`agent.py`（`MetricsAgent`，C/D 档 LLM 调用，复用 `openai.OpenAIClient` 并带磁盘/进程内缓存）、`models.py`（Pydantic 响应模型，如 `RhetoricResult`/`DescriptionResult`/`NarrativeResult`）、`common.py`（分词/分句/统计工具与 `Budget` LLM 预算）、`pipeline.py`（A/B/C/D 四档聚合管线 `compute_report`），以及 `a_*`/`b_*`/`d_*` 规则指标子模块（词法、标点、音特征、句法、词典、主题网络、衔接、可读性、语义级联等）。

## 2. 子命令模块

| 命令 | 模块与主要类/入口 | 说明 |
| --- | --- | --- |
| `gts-fiction` | gts_fiction.py（`GtsFictionOrchestrator` + `write_fiction` 入口） | 从创意/题材生成中文网文（章数、字数、润色指令可配） |
| `write-novel` | write_novel.py（`WriteNovelOrchestrator` + `write_novel` 入口） | 从简介写网文：大纲、章纲、逐章生成、一致性复查 |
| `novel-anls` | novel_anls.py（`BookAnalyzerOrchestrator`）+ novel_anls_agent.py（`NovelAnlsAgent`）、novel_anls_pmt.py、novel_anls_models.py | EPUB 解析、并行章节扫描、多模块聚合分析报告 |
| `metrics` | metrics/tool.py（`MetricsOrchestrator`）、metrics/agent.py（`MetricsAgent`）、metrics/models.py、metrics/pipeline.py 等 | 文本/EPUB 风格与质量评价（A/B/C/D 四档） |

各模块暴露 `reg_subparser(subparsers)` 与 CLI 入口函数，由 `__main__.py` 注册后 `args.func(args)` 派发。

## 3. 共享基础设施

+ `util.py` — 通用工具（`md5`/`gen_objs_md5`、`render_prompt`、`json_dump_model`、`read_yaml_model`/`write_yaml_model`、`read_text`/`write_text`）。
+ `openai.py` — LLM 客户端层（`OpenAIClient`，封装 `call_llm_retry`；`get_msgs_text`/`repl_ins_token`/`ensure_utf8` 辅助）。

## 4. 项目子目录

+ `doc/` — 本项目结构说明文档。
+ `tests/` — pytest 用例（若存在）。
+ `asset/` / `data/` — 静态资源与数据文件。

关键约定与 BookerMarkdownTool 一致：子命令名 `sub-cmd` 对应模块 `sub_cmd.py`；在 `<sub_cmd>.py` 中写 `reg_subparser(subparsers)`，再到 `__main__.py` 中注册。
