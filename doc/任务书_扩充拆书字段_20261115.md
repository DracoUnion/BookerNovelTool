# 任务书：BookerNovelTool 拆书字段扩充（删旧留新 + 训练数据字段）

> 本任务书基于你提供的四个实际文件：`novel_anls.py`、`novel_anls_pmt.py`、`novel_anls_models.py`、`novel_anls_agent.py`（文件名为 `import json.txt` 的那份，类名 `NovelAnlsAgent`）。
>
> **两项核心原则**：
> 1. 新旧字段语义冲突时，**一律保留新字段、删除旧字段**。
> 2. **跨书扫描暂不做**；但用于模型训练的章节级和全书级字段**必须存在于 schema 中**（可为 `Optional`、默认 `None`，由后续数据 pipeline 填充，不要求拆书 LLM 全部生成）。

## 五、训练数据字段（本次必须存在于 schema 中）

### 5.1 章节级训练数据：`TrainingSample` 模型

在 `novel_anls_models.py` 中定义（放在 `ChapterSummary` 之前，避免前向引用问题；或使用 `model_rebuild()`）：

```python
class TrainingSample(BaseModel):
    """章节级训练数据样本。字段存在即满足要求；大部分由数据 pipeline 填充。"""

    # ── 文本片段与切分（程序填充）──
    chunk_id: Optional[str] = None
    chunk_text: Optional[str] = None
    chunk_word_count: Optional[int] = None
    chunk_start_paragraph: Optional[int] = None
    chunk_end_paragraph: Optional[int] = None
    segmentation_strategy: Optional[Literal["natural_paragraph","scene_boundary","sliding_window"]] = None
    overlap_paragraphs: Optional[int] = None
    semantic_coherence_score: Optional[float] = None

    # ── 指令与任务构造（LLM 可生成 / 模板填充）──
    instruction: Optional[str] = None
    instruction_type: Optional[Literal["续写","改写","风格迁移","情节扩写","对话生成","伏笔回收"]] = None
    input: Optional[str] = None
    system_prompt: Optional[str] = None
    prompt_template_id: Optional[str] = None
    output: Optional[str] = None
    messages: Optional[List[Dict[str, str]]] = None

    # ── 风格迁移专用 ──
    style_label: Optional[str] = None
    source_style_label: Optional[str] = None
    style_features: Optional[Dict[str, Any]] = None
    content_description: Optional[str] = None

    # ── DPO 偏好数据 ──
    prompt: Optional[str] = None
    chosen: Optional[str] = None
    rejected: Optional[str] = None
    preference_dimension: Optional[Literal["style_fidelity","plot_reasonableness","character_consistency","rhythm_control","avoid_ai_tone","avoid_cliche"]] = None
    preference_strength: Optional[int] = Field(None, ge=1, le=5)
    preference_source: Optional[Literal["human","editor","rule","strong_model"]] = None

    # ── Agent 轨迹 ──
    observation: Optional[str] = None
    thought: Optional[str] = None
    action: Optional[str] = None
    action_input: Optional[Dict[str, Any]] = None
    action_output: Optional[Dict[str, Any]] = None
    step_index: Optional[int] = None
    is_terminal: Optional[bool] = None

    # ── 质量与合规 ──
    quality_scores: Optional[Dict[str, int]] = None
    overall_quality: Optional[float] = None
    duplicate_flag: Optional[bool] = None
    copyright_risk: Optional[Literal["safe","needs_review","blocked"]] = None
    pii_removed: Optional[bool] = None
    source_trace: Optional[Dict[str, Any]] = None

    # ── 格式与配置 ──
    data_format: Optional[Literal["chatml","alpaca","sharegpt","dpo_pair"]] = None
    language: Optional[str] = None
    split: Optional[Literal["train","val","test"]] = None
    sample_weight: Optional[float] = None
```

**生成责任划分**：

| 字段组 | 生成方 | 说明 |
|---|---|---|
| 文本片段与切分 | orchestrator 程序填充 | 基于 `Chapter.text` 按策略切分；`chunk_id` 用 `{book_title}_{chapter_index}_{seq}` |
| 指令与任务构造 | `SCAN_PMT` 可生成或代码模板填充 | `instruction`/`output`/`messages` 可由 LLM 基于片段生成；`system_prompt` 从模板池随机选取 |
| 风格迁移专用 | `SCAN_PMT` 生成 | `style_label`、`content_description` 可由 LLM 判断；`style_features` 由程序计算（句长、对话占比等） |
| DPO 偏好数据 | 独立 pipeline | 本次仅定义 schema，不生成 |
| Agent 轨迹 | 独立 pipeline | 本次仅定义 schema，不生成 |
| 质量与合规 | 程序 + 独立 pipeline | `duplicate_flag`、`copyright_risk`、`pii_removed` 由程序填；`quality_scores` 可后续 LLM 打 |
| 格式与配置 | orchestrator 程序填充 | `data_format` 默认 `chatml`；`language` 默认 `zh`；`split` 按比例分配 |

**本次要求**：`TrainingSample` 的**全部字段**必须出现在 `ChapterSummary.model_json_schema()` 中。P2 开关关闭时，`training_sample` 可为 `None`。

def save_report(self, output_path: str = "book_analysis_report.json") -> None:
    training_meta = None
    if getattr(self.args, 'build_training_meta', False):
        training_meta = self._build_training_dataset_meta()
    report = BookAnalysisReport(
        book_meta=self.book_meta,
        total_chapters=len(self.summaries),
        chapter_summaries=self.summaries,
        modules=self.report,
        training_dataset_meta=training_meta,
    )
    # ... 原保存逻辑

def _build_training_dataset_meta(self) -> TrainingDatasetMeta:
    samples = [s.training_sample for s in self.summaries if s.training_sample is not None]
    task_counts: Dict[str, int] = {}
    template_counts: Dict[str, int] = {}
    for s in samples:
        if s.instruction_type:
            task_counts[s.instruction_type] = task_counts.get(s.instruction_type, 0) + 1
        if s.prompt_template_id:
            template_counts[s.prompt_template_id] = template_counts.get(s.prompt_template_id, 0) + 1
    chunk_words = [s.chunk_word_count for s in samples if s.chunk_word_count]
    return TrainingDatasetMeta(
        dataset_name=self.book_meta.book_title,
        dataset_version="v1",
        total_samples=len(samples),
        sample_count_by_task=task_counts,
        chunk_count=len(samples),
        avg_chunk_word_count=sum(chunk_words) / len(chunk_words) if chunk_words else None,
        prompt_template_coverage=template_counts,
        source_book_count=1,
        license=getattr(self.args, 'license', None),
        data_origin_pipeline="BookerNovelTool/v1",
    )

## 十、风险提示

1. **`foreshadowing_payoff` 单章可见性**：单章扫描看不到未来回收，`ForeshadowingPayoff.set_chapter` 只能填“本章回收了之前哪章的伏笔”，必然 ≤ 当前章。全书级 `foreshadowing_master_table` 由聚合模块基于全部章节摘要生成，两者分工在 `SCAN_PMT` 与 `AGGREGATE_PMT_FORESHADOW` 中分别写清。
2. **`character_list` 替代 `new_characters`**：`CharacterBrief.is_new` 需在 `SCAN_PMT` 中明确“本章首次登场填 `true`，已有角色填 `false`”，否则模型可能全部填 `true`。
3. **`TrainingSample` 字段过多**：P0 分析字段已使 `SCAN_PMT` 输出约 25 键，再加 40 个训练字段会显著膨胀。**建议**：训练样本字段不要求在 `SCAN_PMT` 中全部生成，而是让 `training_sample` 默认为 `None`；仅当启用训练数据生成开关时，在 `SCAN_PMT` 中追加 `instruction`、`instruction_type`、`output`、`style_label`、`content_description` 这 5 个核心字段，其余由代码 pipeline 后填。`TrainingSample` 模型本身保留全部字段，确保 schema 存在。
4. **`emotion_curve` 类型放宽**：`RhythmModule.emotion_curve` 从 `str` 改 `Union[str, List[Dict]]` 后旧 prompt 输出字符串仍可解析；建议 `AGGREGATE_PMT_RHYTHM` 改为要求输出结构化列表。
5. **`MODULE_CLASS_MAP` 键一致性**：模块数从 10 变 12，两个 map 必须同时更新，否则 `_run_stage2` 在遍历 `MODULE_CLASS_MAP.keys()` 时对缺失键的 `AGGREGATE_PROMPT_MAP[module_name]` 会 KeyError。
6. **破坏性变更**：删除旧字段后，下游依赖旧 JSON 键（`chapter`、`summary`、`new_characters` 等）会失效。任务书第二节的删除清单应作为“旧键 → 新键”映射表同步给下游。
7. **训练数据元信息构造依赖 `training_sample`**：若 `SCAN_PMT` 未生成 `training_sample`，`_build_training_dataset_meta` 会返回 `total_samples=0` 的元信息。这是预期行为——训练数据需要独立 pipeline 配合，本次只保证 schema 与汇总入口存在。
